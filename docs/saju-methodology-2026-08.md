# 사주 계산·해석 기준 (2026-08)

## 계산 순서

1. 양력 또는 음력 입력을 양력 날짜로 정규화합니다.
2. 한국천문연구원 역서 기반 24기 입기 시각으로 월주와 절입 경계를 계산합니다.
3. 법정시에서 서머타임을 되돌리고, 출생지 경도 차이와 날짜별 균시차를 더해 진태양시를 계산합니다.
4. 사용자가 고른 전통 자시 또는 야자시·조자시 기준으로 날짜 경계를 처리합니다.
5. 년·월·일·시주, 지장간, 십성, 통근, 투간, 합충형해파, 대운을 계산합니다.

브라우저에는 1920~2100년 절기 원자료를 압축한 배열만 전달합니다. 원자료 4,343건 중 2030년 우수 시각 한 건은 제공 파일에 없으며, 월주 경계에 쓰는 12절에는 결손이 없습니다.

## 해석 순서

해석은 하나의 점수로 합쳐 단정하지 않고 세 축을 따로 봅니다.

- **구조**: 월령, 격국 후보, 투간·통근, 상신의 존재와 작동 가능성
- **균형**: 일간의 세력, 생조·설기·제어 관계, 억부 용신 후보
- **조후**: 계절의 한난과 조습을 각각 계산한 조후 용신 후보

일간 중심 용신과 격국 중심 용신은 서로 다른 판단법으로 보존하고, 교집합이 작을 때는 신뢰도를 낮춥니다. 격국도 단일 이름으로 확정하지 않고 후보, 성립도, 혼잡 여부, 상신을 함께 기록합니다.

## 구매 안내 연결

사주는 파란색 수동 번호의 통계 순위를 바꾸지 않습니다. 사주 계산은 빨간색 자동 구매 안내에서 날짜·시각·게임 수를 개인화하는 보조값으로만 사용합니다. 구매 시점은 재성 자체뿐 아니라 일간의 감당력, 식상생재 연결, 용신 적합도, 대운·세운·일진의 과부하를 함께 봅니다.

이 점수는 명리 체계 안에서 해석의 일관성을 비교하기 위한 값이며, 복권 당첨 확률이나 과학적으로 검증된 예측 확률이 아닙니다.

## 검증

```powershell
npm.cmd run check
npm.cmd run validate:saju
npm.cmd run validate:saju-calendar -- --strict
npm.cmd run evaluate:saju
npm.cmd run validate:separation
```

`validate:separation`은 출생정보를 바꾸어도 로또와 연금복권의 파란색 수동 추천 순위가 달라지지 않는지 확인합니다.

## 참고 원칙

- 공식 역서와 공공 천문 자료는 계산 검증에 사용합니다.
- 현대 논문은 판단축과 검증 설계만 참고하며 문장을 복사하지 않습니다.
- 『자평진전』, 『적천수』, 『궁통보감』 등 고전의 서로 다른 관점을 하나의 정답으로 합치지 않습니다.
- 학파에 따라 자시, 격국, 용신, 대운 계산법이 달라질 수 있으므로 경계 사례에는 불확실성을 표시합니다.
